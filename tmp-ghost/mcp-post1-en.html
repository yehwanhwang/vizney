When you connect Tableau MCP to Claude, Claude can query only what the signed-in Tableau user is allowed to see. But anything it retrieves, such as rows and view data, enters the Claude conversation as a tool result. From that point on, Claude's retention policy and admin settings apply, not Tableau permissions.

Testing each tool on Tableau Cloud's hosted MCP server (mcp.tableau.com) showed that metadata calls carry no sample values but do include calculation formulas and parameter value lists, and that even a failed query can return real values in its error message. For setup, see How to Connect Claude to Tableau Cloud.

1. What does each Tableau MCP tool send to Claude?

Whatever a tool returns is what enters the Claude conversation. Using a site administrator account against the Superstore sample data, the tools returned the following.

  • Metadata (get-datasource-metadata): Field names and data types, relationships between logical tables (join keys), calculation formulas such as SUM([Profit])/SUM([Sales]), and each parameter's current value and range. No sample field values were included. List parameters, however, arrive with their full list of allowed values, and parameter details were returned even when only one field was requested.
  • Data source queries (query-datasource): Aggregated results come back row by row, and row-level values such as order IDs, customer names, and cities are returned as-is when the question asks for them.
  • View data (get-view-data): Returns the summary data of a dashboard's first sheet as CSV. The tool has no row-limit argument, and the tested dashboard returned more than 400 rows in a single response, formatted as displayed, with currency symbols and thousands separators.
  • View images (get-view-image) and workbook files (download-workbook): The file is uploaded to Tableau's S3 storage, and the response contains only a download link that expires after 60 seconds. If Claude can open that link (this depends on its code execution network settings), the file lands in Claude's code execution environment, and once Claude reads the image, the dashboard's KPI figures enter the conversation. If the link is never opened, only an expired URL remains.
  • Listing tools (list-workbooks and others): Content names and descriptions, and in the workbook list, owners' usernames in email format.

Failed calls can carry data as well. Filtering on a customer name that doesn't exist made the query fail, but the error message suggested a real customer name:

Filter validation failed for field "Customer Name". The following values were not found: Aron Hawkins. Did you mean: Aaron Hawkins?

Allowing only the metadata tool still sends formulas and parameter value lists. Data sources that keep customer or account names in a list parameter are worth reviewing before you connect them.

2. What determines what Claude can see?

The scope is set by the site role and permissions of the Tableau account that signs in. Hosted MCP runs every tool call as that user; data sources the user can't access are refused with a 403 error, and the response contains no data. Even so, the permitted scope can be wider than expected.

  • Admin accounts: Signed in as a site administrator, the nine data sources in the Admin Insights project (users, permissions, tokens, event history, and more) were also available to query, and TS Users includes a User Email field. It's safer to connect MCP with an account that sees only the data the work requires.
  • Embedded data sources: Published data sources aren't the only target. On the tested site, all three data sources embedded in the Superstore workbook were reported as queryable.

3. What happens to the data on the Claude side?

Claude's connector policy states that tool call parameters and responses are logged and that data accessed through connectors is subject to Anthropic's privacy policy. Query results remain in the conversation history and follow your plan's chat retention. Even on personal plans that allow training, raw content from connectors and MCP servers is excluded from training data, though content copied directly into the conversation may be included.

Who can see that data is now decided by Claude settings as well. For plan settings, see Using Claude at Work: Data Settings to Check on a Personal Plan; for what organization admins can see, see Can Claude Admins See Your Chats? Team and Enterprise Explained.

For how admins can limit tools and row counts, see Tableau MCP Admin Settings: Limiting Tools, Rows, and Content.
