Site administrators can't turn off Tableau Cloud's hosted MCP server (mcp.tableau.com). Instead, they can restrict which tools are available, how many rows come back, and which content is in scope through the MCP site settings in the REST API, while Claude organization settings decide which tools need approval.

When these settings are applied, they don't all take effect at the same moment: row caps apply to an open session right away, but tool exclusions appear only after the tool list is refreshed in Claude. For what MCP sends to Claude, see Tableau MCP Security: What Data Reaches Claude.

1. What can Tableau site settings restrict?

MCP site settings are set through the REST API (API 3.29, Tableau Cloud June 2026 and later), and only site or server administrators can change them. They apply to every MCP client that connects to the site, not just Claude.

  • Tools (EXCLUDE_TOOLS, INCLUDE_TOOLS): Remove the tools or tool groups you don't use, or keep only the ones you do. Naming a single tool removes just that tool; other tools in the same group stay available.
  • Row caps (MAX_RESULT_LIMIT, MAX_RESULT_LIMITS): Caps results for tools that take a limit argument. Tools without one, such as get-view-data, aren't capped, so tools that need to be blocked belong on the exclusion list.
  • Content scope (INCLUDE_PROJECT_IDS, INCLUDE_DATASOURCE_IDS, INCLUDE_WORKBOOK_IDS, INCLUDE_VIEW_IDS, INCLUDE_TAGS): Only content in the specified projects, data sources, workbooks, views, or tags can be queried, and out-of-scope content is filtered out of listing and search results. Each variable covers different tools (for example, INCLUDE_DATASOURCE_IDS has no effect on workbook and view tools), so the tool scoping page is worth checking.
  • Filter validation (DISABLE_QUERY_DATASOURCE_VALIDATION_REQUESTS): When a filter uses a value that doesn't exist, the error message suggests similar real values. That suggestion comes from filter validation, which can be turned off per site; querying still works.
  • Audit: OAuth sign-ins and tool calls are logged through Tableau's standard activity and audit pipelines.

For example, to exclude the tools that hand over whole files and images and cap query results at 1,000 rows, send the following. POST replaces the site's entire MCP settings list, so check existing settings with GET first.

POST /api/3.29/sites/{site-id}/settings/mcp

{
  "mcpSiteSettings": {
    "settings": [
      { "key": "EXCLUDE_TOOLS", "value": "download-workbook,get-view-image,get-custom-view-image" },
      { "key": "MAX_RESULT_LIMITS", "value": "query-datasource:1000" }
    ]
  }
}

To block view summary data as well, add get-view-data and get-custom-view-data to the exclusion list. Request-level overrides, which would let users change these settings from their own client, are off by default (ALLOWED_REQUEST_OVERRIDES).

2. When do the settings take effect?

Changing the site settings while Claude was connected showed that the two settings take effect at different times.

  • Row caps: After setting query-datasource:2, the very next query in the open session returned only two rows, and the response showed truncationReason: "admin-cap".
  • Tool exclusions: After excluding download-workbook, the tool kept working in the existing session. It disappeared from the tool list once the connector was reconnected, and after the setting was cleared, refreshing the tool list from the ⋯ menu on the Tableau Cloud connector page was enough to bring it back.

After changing tool exclusions, it's worth asking connected users to refresh their tool list or reconnect.

3. What can you control on the Claude side?

Owners on Team and Enterprise plans can go to Organization settings → Connectors, select the Tableau connector, and on the Tools tab set each tool or tool category to Always allow, Needs approval, or Blocked. The setting applies to the whole organization, and members can't override it.

When setting permissions by category, check which tools each category contains. Claude classifies download-workbook, get-view-image, and get-view-data as read-only tools. Setting the whole read-only category to Always allow also allows workbook downloads and view images, so it's safer to set those tools individually to Needs approval or Blocked.

The two settings reach different places. Tableau site settings apply to every MCP client that connects to the site, while Claude's organization settings apply only to Claude accounts in that organization. Data that must not leave Tableau is best blocked in the site settings, with Claude's approval step on the tools that remain.
